# ☕ Al-Asala Cafe | Website Template

A modern, fully responsive, and elegant landing page template for a Coffee & Maamoul shop. Built with pure HTML, CSS, and Vanilla JavaScript. 

*(واجهة موقع احترافية ومتجاوبة لمقهى يقدم القهوة والمعمول، مبنية باستخدام HTML و CSS و JavaScript بدون أي مكتبات خارجية ثقيلة).*

## ✨ Features (المميزات)

* **100% Responsive:** Looks great on mobile, tablet, and desktop.
* **Modern UI/UX:** Warm colors, elegant typography (Cairo font), and smooth micro-interactions.
* **Dynamic Menu:** Filter coffee, Maamoul, and sweets dynamically without reloading the page.
* **Scroll Animations:** Elements fade in beautifully as you scroll down.
* **Working Contact Form:** Simulated form submission with a success state.
* **Clean Code:** Well-structured, easy to read, and heavily commented.

## 🛠️ Technologies Used (التقنيات المستخدمة)

* **CSS3** (Flexbox, CSS Grid, Custom Variables, Animations)
* **Vanilla JavaScript** (DOM manipulation, Event listeners, Intersection Observer for animations)
* **Font Awesome** (Icons)
* **Google Fonts** (Cairo Font)
